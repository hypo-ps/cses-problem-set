# CSES Problem Set

My C++ solutions to the [CSES Problem Set](https://cses.fi/problemset/).

## Dynamic Programming

- Dice Combinations
- Minimizing Coins
- Coin Combinations I
- Coin Combinations II
- Removing Digits
- Grid Paths I
- Book Shop
- Array Description
- Counting Towers

Compiled binaries are not tracked. To build a solution:

```sh
g++ -std=c++17 -O2 -o solution dynamic-programming/Dice_Combinations.cpp
```
